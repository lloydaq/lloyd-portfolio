## Direction contract

THESIS: The portfolio is a component datasheet for an engineer: general description, block diagram, characteristics, test conditions, limits. It refuses the category default of hero + screenshot + identical project cards + skill bars.

OWN-WORLD: Charcoal ground (#16161A) with a raised sheet tone (#1E1E23), warm white ink (#EDE6DA), muted secondary (#A39E94), one sodium-amber accent (#E0A84F) used for live signal paths and focus only. Hairline rules (1px), square corners, ruled tables with tabular numerals, block-diagram linework. Archivo variable (width axis: expanded display, condensed table heads), JetBrains Mono only for literal code tokens and file paths. Light theme is the same sheet printed on paper (#F2EEE6).

STORY: Visitor learns who Lloyd is and that he builds AI software that shows its work; sees TND's pipeline drawn and explorable; believes the judgement because limits and tests sit beside features; opens the case study, repo, or emails.

FIRST VIEWPORT: Top rule with name left, nav right. Left column (~5/12): name set wide at display scale, one-line function statement, two-sentence description, three actions in a ruled strip (Explore projects, View GitHub, Contact). Right column (~7/12): Figure 1, TND's live block diagram; selecting a block prints its spec line under the figure. Mobile: name, statement, actions, then diagram scaled to width.

FORM: Component datasheet, position 3 of 7 on the grounded list (assigned by roll). seed:70846217ec7545ec. Raises: state by stroke pattern + text, never colour alone (jackfield); one figure owns each section, vast quiet ground (catalog sleeve); system states print as set text (phosphor terminal). Signature interaction: explorable block diagram (pointer + keyboard). Motion grammar: one load sequence where the signal path draws block to block; everything else is response motion.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
